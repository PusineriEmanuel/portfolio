## 📋 Descripción

Portfolio personal desarrollado como sitio web responsivo para mostrar mis habilidades, proyectos y experiencia como **Programador FullStack**. El sitio presenta una interfaz moderna y atractiva con efectos interactivos y un diseño adaptable a diferentes dispositivos.

## ✨ Características

- 🎨 **Diseño Responsivo**: Adaptable a dispositivos móviles, tablets y desktop
- 🌟 **Interfaz Interactiva**: Efectos hover, transiciones suaves y animaciones
- 📱 **Navegación Móvil**: Hamburger menu para dispositivos pequeños
- 🎯 **Secciones Organizadas**:
  - Presentación personal
  - Habilidades técnicas con iconos
  - Portfolio de proyectos
  - Enlaces de contacto
- ⚡ **Rendimiento Optimizado**: Carga rápida y código limpio
- 🎪 **Efectos Visuales**: Zoom en elementos, cambios de color dinámicos

## 🛠️ Tecnologías Utilizadas

### Frontend

- **HTML5**: Estructura semántica y accesible
- **CSS3**: Estilos personalizados, flexbox, grid y animaciones
- **JavaScript ES6**: Funcionalidad interactiva y responsive
- **Bootstrap 5.3.3**: Framework CSS para diseño responsivo

### Recursos

- **Bootstrap Icons**: Iconografía moderna
- **Custom CSS**: Estilos personalizados y tema de colores
- **Responsive Design**: Media queries y viewport optimization

## 🚀 Instalación y Uso

### Opción 1: Clonar el repositorio

```bash
git clone https://github.com/PusineriEmanuel/portfolio.git
cd portfolio
```

### Opción 2: Descargar ZIP

1. Descarga el archivo ZIP desde GitHub
2. Extrae los archivos
3. Abre `index.html` en tu navegador

## 💡 Funcionalidades JavaScript

### Responsive Design Dinámico

- **responsiveButtonCol()**: Ajusta botones según el ancho de pantalla
- **responsiveHabSection()**: Modifica el layout de habilidades en móviles
- **cambiarColor()**: Sistema de cambio de colores interactivo

### Event Listeners

- Resize window detection
- Load event optimization
- Interactive navigation

## 🎨 Paleta de Colores

```css
:root {
  --primary-bg: rgb(57, 62, 71); /* Fondo principal */
  --accent-color: rgb(206, 148, 48); /* Color de acento */
  --hover-color: rgb(240, 178, 71); /* Color hover */
  --text-light: white; /* Texto claro */
}
```

## 📱 Responsive Breakpoints

- **Desktop**: > 992px
- **Tablet**: 768px - 992px
- **Mobile Large**: 426px - 768px
- **Mobile Small**: < 425px
